# ADR テンプレート

1 つの決定を 1 ファイルに書く。ファイル名は `ADR-NNNN-<決定のタイトル>.md`（NNNN は topic 内の連番、4 桁ゼロ埋め）。

```markdown
# ADR-NNNN: <決定のタイトル>

日付: YYYY-MM-DD / ステータス: Accepted

## 状況

<何を決める必要があったか。制約と前提。根拠は [[調査ノート]] へリンク>

## 決定

**<決めたこと>。** <理由を 1-3 文>

## 検討した他の案

- **<案>:** <採らなかった理由>（[[<根拠ノート>]]）

## 結果・影響

- <この決定で可能になること / 受け入れるトレードオフ>
- <後続の作業や他の ADR への影響>

## 未検証事項

- <決定の前提のうち裏付けが取れていないもの。なければ「なし」>

## 関連

- [[<調査ノート>]]
- [[<関連する ADR>]]
```

## ステータスの扱い

- 新規は `Accepted`
- 決定を覆すときは旧 ADR の本文を書き換えず、新しい ADR を作る。旧 ADR のステータス行だけを `Superseded by [[ADR-MMMM-<タイトル>]]` に変え、新 ADR の `## 関連` に旧 ADR を置く
