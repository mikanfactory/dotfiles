# ノートテンプレート集

## 調査ノート

事実確認の問い（「〜できるか」「〜の制約」）に 1 つ答える。

```markdown
# <問いのタイトル>

調査日: YYYY-MM-DD / 対象: <org/repo (worktree)>

## 結論

**<できる / できない / 条件付き>。** <1-3 文で要点>

## 根拠

<公式ドキュメント名とリンク>

> <原文の引用>

## 現状の実装

`<path>:<line>`

```<lang>
<コード片>
```

## 派生する制約

| やりたいこと | 可否 |
| - | - |
| ... | ✓ / ✗ |

## 関連

- [[<関連ノート>]]
```

## 案ノート

設計案を 1 つ具体化し、限界を明記する。

```markdown
# Plan <X>: <案の名前>

調査日: YYYY-MM-DD / 対象: <org/repo (worktree)>

<案の要約を 1 段落>

## 現状（コードで確認した事実）

| 項目 | 実装 | 場所 |
| - | - | - |
| ... | ... | `<path>:<line>` |

## 変更内容

### <X>-1. <変更>

...

## この設計の限界

- ...

## 関連

- [[<関連ノート>]]
```

## 比較ノート

```markdown
# <案A> と <案B> の共通部分・相違点

調査日: YYYY-MM-DD / 対象: <org/repo (worktree)>

[[<案A>]] と [[<案B>]] の<観点>を整理する。

## 共通部分

### 1. <項目>

...

## 相違点

| 観点 | <案A> | <案B> |
| - | - | - |
| ... | ... | ... |

## 判断の分かれ目

- ...

## 関連

- [[<案A>]]
- [[<案B>]]
```

## プロンプトログ

`YYYY-MM-DD プロンプト.md`。同日に複数回依頼があれば `---` で区切って追記する。

```markdown
<ユーザーの依頼文をそのまま>

→ <受けた対応を 1 行>

1. [[<作成したノート>]] — <補足>
2. [[<更新したノート>]]（更新）
```
