# 文章の rubric（媒体共通）

媒体を問わず当てる原則の一覧。書く前に一度読み、書いている途中に当て、書き終えたら各行の自己チェックに yes / no で答える。
AI に下書きを任せると、書き手の頭の中の文脈や作業中の呼び名がそのまま残り、他の人が読んでも分からない文書になりがちである。
それを直接防ぐのは「前提知識なしで読めるようにする」「読者を名指しし、読者が知りたい順に章を並べる」「作業中に生まれた呼び名は、読み手がふだん使う言葉に置き換えてから書く」の 3 行である。

媒体ごとの書式（PR 本文なら [`writing-style`](../../create-pr/references/writing-style.md)）とぶつかる行は、媒体側を優先する。

## 構成

| 原則 | なぜ | 自己チェック |
| --- | --- | --- |
| 書く前に、誰のどんな判断・行動を引き出す文書かを 1 文で書く | 目的が無いと、構成・詳しさ・トーンを決める基準が無くなる | 目的を 1 文で言えるか。目的に寄与しない節を削れるか |
| 読者を名指しし、読者が知りたい順に章を並べる | 読者が曖昧だと、前置き過剰や的外れな詳細が増える | 各章は読者のどの問いに答えているか |
| 前提知識なしで読めるようにする | 経緯を知らない人や AI に渡したとき、口頭の補足なしでは伝わらない | 文脈を知らない人が、この文書だけで理解できるか |
| 完全な文で書き、「だから」「そのため」の接続を省かない | 箇条書きは論理の飛躍を隠す | 箇条書きに逃げた段落はないか。人の発言の要約に、本人が言っていない因果を足していないか |
| すべての文に「だから何？」と問う | 答えられない文は読者の時間を奪うだけ | 消しても論旨が変わらない文が残っていないか |
| 同じ事実は文書内の 1 箇所にだけ書く | 切り口を変えて同じ 1 件を何度も書くと、読者は毎回新情報かを判定させられる | 同じ数値・同じ課題名が何回出てくるか数えたか |
| 見出しは主題の名詞句だけにする | 問いや副題を足すと、目次で読んだときに何の節か分からない | 見出しに動詞・問い・副題が残っていないか |

## 主張と根拠

| 原則 | なぜ | 自己チェック |
| --- | --- | --- |
| 形容詞を数値に置き換え、数値には母数と条件を添える | 「大幅に改善」は検証できない。「全体の 10%」の全体が読めないと、意味が桁でぶれる | 裏付けのない形容詞が残っていないか。各数値の母数は本文から一意に読めるか |
| 数字には出典の種類（実測・ヒアリングの感覚値・推定）を添える。手元に無い情報は空欄にして聞く | 推定を実測と同じ書き方にすると、読者はそれで判断してしまう | 感覚値や推定を実測と同じ書き方にしていないか。担当者欄を推測で埋めていないか |
| 自分の推奨は「提案」と書き、「決定」は決めた人が決定と言ったものにだけ使う | 推奨を決定と書くと、本来集めたい意見が集まらない | 「決定」と書いた箇所は、すべて実際に決まったものか |
| 図の矢印はデータが流れる向きに揃え、各矢印の書き手は一次資料で確かめる | 図は本文より先に読まれ、そのまま信じられる | 消しても判断が変わらないノードが残っていないか |

## 言葉と文体

| 原則 | なぜ | 自己チェック |
| --- | --- | --- |
| 作業中に生まれた呼び名は、読み手がふだん使う言葉に置き換えてから書く | 書き手は使い慣れているので自作の語だと気づかず、読み手だけが分からない | 本文・タイトル・表の列名に、作業メモ由来の呼び名が残っていないか |
| 同じ概念の呼び方は 1 つに固定する | 言い換えるたびに、読者は別物かどうかを照合させられる | 同じものを指す語が 2 種類以上出ていないか |
| 平易な語彙で書き、比喩や堅い漢語を避ける | 凝った語は意味がぼやける | 比喩に逃げずに中身を言い切れているか |
| LLM が量産する空虚な型を書かない（「重要なのは〜」「本記事では〜」「不可欠」「包括的」「掘り下げる」「〜の観点から」など） | 論点を増やさずに、書いている感じだけを足す | これらの語を検索して 0 件か。残した語は、消すと意味が変わるか |
| 文脈で分かる断り書きを足さない | 本当に必要な注意が埋もれる | 消したら読者が誤解する場面を 1 つ挙げられるか |
| 話し言葉の縮約（「〜てる」「〜てます」）を書き言葉に直す | 推敲不足に見え、内容より先にラフさが伝わる | い抜き・ら抜き・砕けた口語が残っていないか |
| 太字は 1 文書 2〜3 箇所までにし、ラベルや表のセルには使わない | 太字が多いと強調が埋もれる | 太字が 4 箇所以上ないか |
| 括弧書きの補足を多用しない | 本筋が途切れて読みにくくなる | 1 段落に括弧が 2 つ以上ないか。消しても意味が通る括弧はないか |
| 半角英数字と全角文字の境目に半角スペースを入れる | 密着していると読みにくい | 英数字と日本語が直接くっついている箇所がないか |

## 推敲

| 原則 | なぜ | 自己チェック |
| --- | --- | --- |
| 公開の直前と、まとまった手直しの直後に、文の壊れだけを見るパスを 1 回通す | 変換ミスや係り受けのねじれは、手で直す作業そのものからも生まれる | 声に出して読んで詰まる箇所はないか。まとめと各見出し直後の 1 文に壊れがないか |
| 主題や中心の用語を変えたら、宣言文・見出し・未対応の指摘を新しい主題で洗い直す | タイトルだけ直すと、旧主題の宣言文や見出しが残り、読者が主題を取り違える | 旧用語の残りは 0 件か |
